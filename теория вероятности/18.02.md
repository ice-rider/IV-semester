P(Ω) = 1(условие нормированности)А4. Если А,В несовместны (то есть АВ = ∅), то Р(А+В) = Р(А) + Р(В)Следствие 1.&nbsp;            \_Р(А) = 1 - Р(А)из аксиомы А3&nbsp;                \_P(Ω) = 1 = P(A + A) =>A \& -A события не совместные.по аксиоме А4 вероятность равна сумме вероятностей&nbsp;        \_=> P(A) + P(A)Следствие 2.P(∅) = 0Следствие 3.Р(А + В) = Р(А) + Р(В) - Р(АВ)Следствие 4.Р(А+В) <= P(A) + P(B)Следствие 5.если А ⊆ В, то Р(А) <= Р(В)Следствие 6.0 <= Р(А) <= 1### Дискретное вероятностное пространство. Классическая формула для вероятности.пространство элементарных событий Ω, совокупность подмножеств Ω. образующих алгебру F или σ-алгебру F\*, которые и считаются случайными событиями и, наконец, функция вероятности Р удовлетворяющая аксиомам А1-А5тройка <Ω,F,P> называется *вероятностным пространством* При изменении любого элемента изменяется и вероятностное пространствобросается 2 монетыΩ = (ГГ, ГР, РГ, РР)каждому можно приписать одинаковую вероятность 1/4однако возможно ситуация когда нас интересует только одинаковые или различные исходы подбрасываний монету, и тогда в качестве омега возможно стоит выбрать множество из трех равных однозначных элементов (ГГ РР, Различные исходы). Как уже отмечалось выбор пространства обосновывается тем, насколько согласуются получающиеся выводы с практическими результатами экспериментаНаиболее простым и в то же время самым массовым с точки зрения приложений в различных науках является дискретное вероятностное пространство с конечным множеством элементарных событийпусть омега конечное множествоΩ = {ω1, ω2, .., ωN}*классическая формула:*Рассмотрим произвольное событие А = {ωi1, ωi2, …, ωik}|Ω| = n|A| = kP(A) = k / n    (все события равновероятные)ПРИМЕРЫ:ребенок играет кубиками выложил слово "математика".
