## Аксиоматика Холмогорова.

эту теорию (аксиоматическую) разработал Андрей Николаевич Холмогоров

***произвольное множество Ω*** называется множеством или пространством элементарных событий

Примеры:

1. Монета Ω = { Орел, Решка }
2. Кубик Ω = { 1, 2, ..., 6 }
3. Ω = { 0, 1, 2, ...}

***счетные множества*** - множества элементы которых можно пронумеровать.

4. стрелок стреляет в круглую мишень. любая точка (х,у) - элементарное событие. значит множество всех точек - множество Ω. (множество бесконечно и их нельзя занумеровать)

***множества континум***

гипер континум - 2 в степени континум (взять множество континум и из подмножеств сделать новое множество)

***случайным событием А*** называется подмножество множества Ω.  А <= Ω

Кубик

Ω = { 1, 2, 3, 4, 5, 6 }

A = { 2, 4, 6 }

В = { 1, 3, 5 }

C = { 5, 6 }

событие А - при бросании кубика выпало четное число очков

(прописная п)

p(Ω) - множество всех подмножеств

|A| - число элементов (если конечно, и мощность множества если оно беск.)

|Ω| - 6

|p(Ω)| = 64

∅ ⊆ Ω - невозможное событие (не происходит никогда особенно физически)

Ω ⊆ Ω - достоверное событие (происходит обязательно)

## Операции с событиями:

1. А + В = А U B  (произошло А ***или*** В)
2. А \* В = А ∩ В  (произошло А ***и*** В)
   А \* В = ∅      (А и В ***несовместные*** события)
3. А \\ В          (А ***но не*** В. А произошло, В не произошло)
   _
4. А              (дополнение до всего универсума) универсум - все множества

множество вместе с операциями образуют ***Булеву алгебру*** множеств.

события вместе с операциями образуют ***Булеву алгебру*** событий.     (наш случай)

## Булева алгебра событий

наша цель предать событиям числовое значение вероятности. вероятность это вещественное число.

1. если Ω конечна, |Ω| = 12, |p(Ω)| = 2^12
2. Ω - счетное, р(Ω) - континуум
   все подмножества - события
3. Ω - континуум, р(Ω) - гиперконтинуум

(чисел континуум, подмножеств гиперконтинуум. чисел не хватит)

## Алгебра событий

алгебра F событий - это совокупность событий удовлетворяющих условию

1. Ω ∈ Φ
   _
2. А,В ∈ F => A+B, A\*B, A ∈ F

примеры:

1. F = { Ω, ∅ }  - тривиальная алгебра
2. алгебра квадрируемых множеств на плоскости

квадрируемые множества - алгебра множеств имеющих площадь.

3. В = [x1, x2]; [x1,x2); (x1,x2]; (x1,x2) - алгебра Барельевских множеств.

расширим множество всеми возможными расширениями и дополнениями.

если потребовать чтоб эта алгебра была замкнута относительно счетных сум и произведений

А1, А2, ..., Ан ∈ F => U(i..inf) Ai ∈ F

получили сигма алгебра.
