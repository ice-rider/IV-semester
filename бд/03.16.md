# Типы соединений



## 1. перекрестное соединение - CROSS JOIN



соединенную таблицу образуют все возможные сочетания строк, набор ее столбцов - стобцы т1 и следующие за ним столбцы т2



```sql
SELECT *
  FROM товары CROSS JOIN заказы;
```

|ид заказа|ид товара|кол-во|

|123|1|5|
|123|2|10|
|234|4|10|

|ИД товара|Название|Цена|ИД заказа|ИД товара|Кол-во|

## 2. Внутреннее соединение INNER JOIN

`T1 [INNER] JOIN T2 ON <условие соединения>`   
`T1 [INNER] JOIN T2 USING (<список столбцов>)`
`T1 NATURAN [INNER] JOIN T2`


для каждой строки R1 из таблицы Т1 в результирующей таблице содержится строка из таблицы Т2 удовлетворяющая условию соединения.

```sql
SELECT *
  FROM T1 INNER JOIN T2 ON T1.ID Товара = T2.ID Товара;
```

|ИД товара|Название|Цена|ИД заказа|ИД товара|Кол-во|
|-|-|-|-|-|-|
|1|кроссовки|2000|123|1|5|
|2|футболка|800|123|2|10|

---

Товары

|РК|ИД Товара|название|цена|
|-|-|-|-|


Заказы

|`РК` ИД Товара|`РК`,`FK` ИД заказа|кол-во|
|-|-|-|

`PK` - primary key - первичный ключ
`FK` - foreign key - внешний ключ

Связь **ОДИН КО МНОГИМ** необязательная со стороны товара

Заказы.ИД Товара -> Товары.ИД Товара


## 3. Левое внешнее соединение (LEFT OUTER JOIN)

`T1 LEFT [OUTER] JOIN T2 ON <условие соединения>`  
`T1 LEFT [OUTER] JOIN T2 USING (<Список столбцов>)`  
`T1 NATURAL LEFT [OUTER] JOIN T2`  

в начале выполняется внутреннее соединения, затем в результат добавляются строки затем в результат добавляются все строки из Т1 которым не соответствуют строки в Т2 а вместо значений из Т2 вставляются NULL (пустые)  
результат всегда содержит минимум 1 строку из таблицы Т1

```sql
SELECT *
  FROM T1 LEFT OUTER JOIN ON T1.ID Товара = T2.ID Товара
```

|ИД товара|Название|Цена|ИД заказа|ИД товара|Кол-во|
|-|-|-|-|-|-|
|1|кроссовки|2000|123|1|5|
|2|футболка|800|123|2|10|
|3|Бейсболка|1500|NULL|NULL|NULL|


## 4. Правое внешнее соединение (RIGHT OUTER JOIN)

`T1 RIGHT [OUTER] JOIN T2 ON <условие соединения>`  
`T1 RIGHT [OUTER] JOIN T2 USING (<Список столбцов>)`  
`T1 NATURAL RIGHT [OUTER] JOIN T2`  

в начале выполняется внутреннее соединения, затем в результат добавляются строки затем в результат добавляются все строки из Т2 которым не соответствуют строки в Т1 а вместо значений из Т1 вставляются NULL (пустые)  
результат всегда содержит минимум 1 строку из таблицы Т2

(по аналогии с левым соединением, но зеркально)


```sql
SELECT *
  FROM T1 RIGHT OUTER JOIN ON T1.ID Товара = T2.ID Товара
```

|ИД товара|Название|Цена|ИД заказа|ИД товара|Кол-во|
|-|-|-|-|-|-|
|1|кроссовки|2000|123|1|5|
|2|футболка|800|123|2|10|
|NULL|NULL|NULL|234|4|10|


**наличие заказа и отсутствии товара - нарушение условий**  
*наличие товара без заказа допустимо*


*по возможности следует отказаться от использования правое соединение (можно всегда использовать левое)*


## 5. Полное внешнее соединение (FULL OUTER JOIN)

`T1 FULL [OUTER] JOIN T2 ON <условие соединения>`  
`T1 FULL [OUTER] JOIN T2 USING (<Список столбцов>)`  
`T1 NATURAL FULL [OUTER] JOIN T2`


```sql
SELECT *
  FROM T1 FULL OUTER JOIN ON T1.ID Товара = T2.ID Товара
```

# Виды условий соединения

1. `ON <логическое выражение>` - пара строк соответствет друг другу если логическое соответствие возвращает истину  
  `ON T1.IDProduct == T2.Product`  
  `ON Содержит(Районы УР.Граница, НацПункты.Координаты)`
```sql
SELECT * 
  FROM команды AS К1 JOIN Команды AS K2
    ON  K1.Rating >= K2.Raiting 
    AND K1.ID <> K2.ID
```
2. `USING (<список столбцов>)` - сокращенная запись условия когда с обеих сторон столбцы имеют одинаковые имена и соответствует условию с равенством столбцов  
  `T1 JOIN T2 USING (.ИД Товара)` ~ `Τ1 JΟΙΝ T2 ON (T1.ИД Товара = Т2.ИД Товара)`

```sql
SELECT *
FROM T1 FULL OUTER JOIN T2 USING (.ИД Товара)
```  

|ИД товара|Название|Цена|ИД заказа|Кол-во|
|-|-|-|-|-|
|1|кроссовки|2000|123|5|
|2|футболка|800|123|10|
|3|Бейсболка|1500|NULL|NULL|
|4|NULL|NULL|234|10|

из пары сопоставленных столбцов выводится только один. За ним оставшиеся столбцы из Т1 и Т2

3. `NATURAL JOIN` (сокращенная форма USING) - соответствует использованию USING со всеми именами столбцов совпадающими в обеих таблицах   
  `T1 NATURAL JOIN T2` ~ `T1 JOIN T2 USING (имена совпадающих столбцов всех!)`

```sql
SELECT *
FROM T1 NATURAL FULL OUTER JOIN T2;
```

|-|-|-|-|-|
|1|кроссовки|2000|123|5|
|2|футболка|800|123|10|
|3|Бейсболка|1500|NULL|NULL|
|4|NULL|NULL|234|10|
