# Нормализация баз данных

## Аномалии данных

### Аномалия удаления данных

Если меняется название факультета или номер телефона деканата, нужно заменять это значение во всех записях, которые их содержат. Если по ошибке часть записей будет удалена, БД придет в неконсистентное состояние.

### Пример нарушения нормальных форм

Таблица: `ид студента, ид дисциплины, оценка, преподаватель`

- Составной ключ: `ид дисциплины, ид студента`
- Зависимость: `ид дисциплины → преподаватель`
- Нарушение: **2НФ** (функциональная зависимость неключевого атрибута от части первичного ключа)

---

## Нормальная форма Бойса-Кодда (BCNF)

1. Таблица находится в третьей нормальной форме.
2. Должны отсутствовать зависимости атрибутов первичного ключа от неключевых атрибутов.

> Ситуация, когда таблица находится в 3НФ, но не в BCNF, возникает если таблица имеет 2 или более потенциальных ключа, которые являются составными и имеют общий атрибут. В остальных случаях 3НФ и форма Бойса-Кодда эквивалентны.

### Пример: бронирование залов для мероприятий

| зал | время начала | время окончания | тариф             |
| --- | ------------ | --------------- | ----------------- |
| 1   | 18:02        | 18:35           | зал 1 без питания |

Так как в тариф включается информация о зале, возникает ошибка.

**Требование BCNF:** в данной форме должны отсутствовать зависимости атрибутов первичного ключа от неключевых атрибутов.

## Пример ошибки из диплома

### Исходная структура (с нарушениями)

**Пользователь:**
- Уникальный номер
- Логин
- Пароль
- Номер телефона

**Анкета:**
- Уникальный номер
- Вопросы
- Ответы
- Результат анкеты

> Нарушается связь между таблицами и первые 2 нормальные формы. Необходимо сделать отдельную таблицу для связи многие-ко-многим.

### Исправленная структура (по Соловьёвой)

**Пользователь и Анкета (связующая таблица):**
- ИД пользователя
- ИД анкеты

**Вопросы:**
- ИД вопроса
- Текст

**Пользователь:**
- ИД пользователя
- Логин
- Телефон
- Тариф

**Результат:**
- ИД пользователя + ИД вопроса (ПК)
- Ответ

# Запросы SELECT

## Возможности

- Вывод произвольных значений
- Вывод всех строк таблицы
- Вывод данных из определенных столбцов таблицы

## Типы данных

### Константы

**Строковые** — заключены в одинарные кавычки (двойные для имён полей и таблиц).

**Числовые:**
- Целые: `1`, `-551`
- Вещественные: `1.0`
- Вещественные в экспоненциальной форме: `1e-3`

**Дата и время:**
```sql
'1991-01-08 04:05:06'
```

**Логические:**
- `TRUE`, `FALSE`
- `1`, `0`

---

## Операторы

Так же как в программировании, но:
- Деление по модулю — `MOD`
- Целочисленное деление — `DIV`

### DISTINCT

Данный оператор в сочетании с `SELECT` позволяет выбирать только уникальные записи.

### Условный оператор WHERE

```sql
SELECT [DISTINCT] fields
FROM table
WHERE <conclusion>
```

### Логические операторы

- `NOT`
- `OR`
- `AND`
- `XOR`

### Операторы IS NULL, BETWEEN, IN

- **BETWEEN** — позволяет задать 2 границы и сделать выборку.
- **IN** — позволяет проверить, входит ли запись в список значений.

### Оператор LIKE

```sql
строка LIKE шаблон
```

В шаблоне могут использоваться символы-заменители:
- `%` — любая последовательность символов
- `_` — единичный символ

---

## Строковые функции

### SUBSTRING

```sql
SUBSTRING(str, pos, [len])
```

Пример:
```sql
SELECT SUBSTRING('sql query', 1, 3);  -- 'sql'
```

### TRIM

```sql
TRIM([LEADING | TRAILING | BOTH] [FROM] string_text, [characters])
```

Пример:
```sql
TRIM(BOTH 'xyz' FROM 'yxTomxx')  -- 'Tom'
```

### UPPER, LOWER

- `UPPER()` — перевод в верхний регистр
- `LOWER()` — перевод в нижний регистр (по умолчанию)

### Конкатенация строк

```sql
string || string  -- конкатенация строк
```

### OVERLAY

```sql
OVERLAY(string PLACING substring FROM position [FOR count])
```

## Функции преобразования

- `TO_CHAR(value, format)` — преобразование в строку
- `TO_DATE()` — преобразование в дату
- `TO_NUMBER()` — преобразование в число

## Функции работы с датой

- `DATE_PART()` — извлечение части даты
- `EXTRACT()` — извлечение компонента даты/времени

---

## Математические функции

**Основные:**
- `ABS()`, `FLOOR()`, `CEIL()`, `ROUND()`, `TRUNC()`

**Арифметические:**
- `MOD()`, `DIV()`, `POWER()`, `EXP()`, `SQRT()`, `SIGN()`

**Случайные числа:**
- `RANDOM()` — генерация случайного числа
- `SETSEED()` — установка начального значения

## Агрегатные функции

- `COUNT()` — подсчёт строк
- `SUM()` — сумма значений
- `AVG()` — среднее значение
- `MIN()` — минимальное значение
- `MAX()` — максимальное значение
