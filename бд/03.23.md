# Выборка данных

```sql
SELECT список_выборки
FROM табличное_выражение
[настройки сортировки]
```

*список_выборки* - константы имен столбцов, выражения над столбцами

*табличное_выражение* - после него могут быть:
- WHERE
- GROUP BY
- HAVING


## `WHERE <условие_отбора_строк>`

строки таблиц которые были отобраны с помощью `where` можно сгруппировать используя `group by`

## предложение `GROUP BY` для группировки строк

строки таблицы прошедшие фильтр where можно сгруппировать с помощью `GROUP BY`, а затем оставить только нужные группы используя `HAVING`

```sql
SELECT список_выборки
FROM ...
[WHERE ...]
GROUP BY ..группирующие столбцы;
```

## пример группировки

объединяет строки в группу по одинаковым значениям группирующего столбца.

SELECT product_name
FROM orders 
GROUP BY product_name;

```sql
SELECT product_name, max(price), avg(quantity)
FROM orders 
GROUP BY product_name;
```

после предложения селект можно выводить только те столбцы по которым проводилась группировка, над остальными столбцами только агрегатные функции

## основные агрегатные функции

`avg(выражение) - среднее для всех значений отличных от NULL`  
`max(выражение) - максимальное по всем не пустым значениям`  
`min(выражение) - минимальное по всем не пустым значениям`  
`sum(выражение) - сумма по всем не пустым значениям`  

если нет ни одного значения отличного от `NULL` то сама функция также выдаст `NULL`

`count(*) - кол-во строк`

для пустого набора выведет 0

*агрегирующие функции не обязательно использовать вместе с `GROUP BY`:*
```sql
SELECT avg(quantity)
FROM orders;
```

|avg|
|-|
|10|

---

```sql
SELECT date_part('year', order_date) AS 'order_year', product_name, sum(quantity) AS total_quantity
FROM orders
GROUP BY date_part('year', order_date), product_name;
```
запрос который для каждой даты будет извлекать ту часть даты которую мы запросим. для каждой даты будет извлечен год заказа и группируем именно по году. тогда мы только данные группировки можем вывести в том же формате (внутри селекта пишется такая же функция)

|order_year|product_name|total_quantity|
|-|-|-|
|2022|Товар А|200|
|2023|Товар В|150|
|2023|Товар С|100|


# HAVING

having используется как `WHERE`, но применяется уже после группировки по результатам группировки  

если таблица была сгруппирована но интерес представляют только некоторые группы, то их можно отфильтровать с помощью педложения `HAVING`. после `HAVING` могут использоваться группирующие столбцы и агрегатные функции над другими столбцами

[ранее](#пример-группировки)  


```sql
-- старый запрос
SELECT product_name, max(price), avg(quantity) 
FROM orders
GROUP BY product_name
-- дополнение старого запроса
HAVING count(*) >= 10
-- or 
HAVING max(price) > 100.0
-- or
HAVING max(price) > (SELECT ...)
```


# ПОДЗАПРОСЫ

## Типы подзапросов

1. ### Список VALUES 
```sql
SELECT name
FROM (VALUES('Товар 1', 1000.0),
            ('Товар 2', 5000.0)
            ('Товар 3', 700.0)) AS product(name, price);
```
*вырвано из контекста*

2. ### Скалярные подзапросы
> возвращают одну строку и 1 столбец, могут использоваться в операторах сравнения

```sql
-- пример общего запроса использующего подзапрос
SELECT *
FROM orders
WHERE order_date = ( -- скалярный подзапрос
    SELECT min(order_date) 
    FROM orders);
```

3. ### запрос со словом `EXISTS`
> используется в условии `WHERE EXISTS (<подхапрос>)`

*функция возвращает истинну если есть хотя бы одна строка в результате подзапроса, иначе ложь*

```sql
SELECT customer_name, phone
FROM customers
WHERE EXISTS (
    SELECT 1
    FROM archive_customers
    WHERE id = customers.cust_id);
```

4. ### Подзапросы с оператором `IN`
> подзапрос должен возвращать ровно 1 столбец

`WHERE выражение IN (подзапрос)`  
`WHERE выражение NOT IN (подзапрос)`  

выражение сравнивается со значениями во всех строках в этом столбце

```sql
SELECT customer_name, phone
FROM cuctomers
WHERE cust_id IN (
    SELECT id
    FROM archive_customers);
```

5. ### Подзапросы со словом `ANY (SOME)`
> `ANY` - хотя бы 1, `SOME` - несколько

`выражение <оператор проверки условия> ANY(подзапрос);`

подзапрос должен возвращать **ровно один столбец**.  
выражение сравнивается с каждой строкой под запроса

`true`, если хотя бы для **одной строки** условие истинно  
`false`, если хотя бы для **всех** строк условие ложно  
`NULL`, если хотя бы для **одной** строки условие возвращает `NULL`  


```sql
SELECT *
FROM new_orders
WHERE quantity > ANY(
    SELECT quantity
    FROM orders
    WHERE {в прошлом месяце} );
-- {} - здесь должна быть функция для отбора дат (лень писать)
```

6. ### Подзапрос с `ALL`

`выражение <оператор проверки условия> ALL(подзапрос)`

*то же что и `NOT IN`

`true`, если истинно условие для всех строк  
`false`, если ложно хотя бы для **одной строки**

```sql
SELECT *
from new_orders

WHERE quantity > ANY (SELECT quantity
    FROM orders
    WHERE {в прошлом месяце} );
-- допустим подзапрос выдаст (200, 230, 270)
-- отберет все что БОЛЬШЕ 200

WHERE quantity > ANY (SELECT quantity
    FROM orders
    WHERE {в прошлом месяце} );
-- отберет все что БОЛЬШЕ 270
```




# Возврат данных из измененных строк

Запросы на модификацию данных
```sql
INSERT INTO groups(group_name, graduated)
VALUES
    ('Б24-782-1', false),
    ('Б24-782-2', true),
    ('Б21-784-1', true);
-- посмотрим на таблицу
```

```sql
CREATE TABLE groups(
    group_id SERIAL PRIMARY KEY,
    group_name TEXT,
    graduated BOOLEAN
)
```

Groups
|group_id|group_name|graduated|
|-|-|-|
|1|Б24-782-2|true|

```sql
INSERT INTO groups(group_name, graduated)
VALUES
    ('Б24-782-1', false),
    ('Б24-782-2', true),
    ('Б21-784-1', true)
RETURNING group_id;
-- "возвращая при этом"
```
