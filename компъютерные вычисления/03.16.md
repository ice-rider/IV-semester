# Решение систем линейных алгебраических уравнений

## Метод Гаусса для решения СЛАУ

**СЛАУ** - системы линейных алгебриаических уравнений

метод гаусса относится к __*прямым методам*__ решения СЛАУ

**прямые методы** - методы приводящие к решению за конечное число арифметических операций. если операции реализуются точно, то и результат будет точным. Поэтому *другое название этих методов - точные методы*

если возникает округление то результаты даже точныъ методов будут приближенными.


### Суть метода Гаусса
суть метода Гаусса заключается в последовательном исключении неизвестных, при этом с целью хорошей алгоритмизации в вычмате равносильным преобразованиям подвергаются не сами уравнения, а матрица коэффициентов А и вектор свободных членов В которые объеденины в одну расширенную матрицу.

метод имеет прямой и обратный ход

#### прямой ход 
прямой ход состоит в исключении элементов находящихся ниже главной диагонали матрицы коэффициентов А

```
Ap = a11 a12 ... a1n | b1  
     a21 a22 ... a2n | b2  
     ... ... ... ... | ...  
     am1 am2 ... amn | bn  
```

```
Ap'=  1  C12 ... C1n | d1  
     a21  1  ... C2n | d2  
     ... ...  1  ... | ...  
      0   0  ...  1  | dn  
```

### Особенности прямого хода
1. матрица А преобразуется к верхне-треугольному виду с еденицами на главной диагонали
2. Получение матрицы А расширенная включает в себя следующие действия:
   - каждый элемент строки в которой находится ведущий элемент (это а11 в 1 строке, а22 в 2 строке итд..) делится на него

### обратный ход
от матрицы А расширенной штрих переходим к системе уравнений которая включает в себя х1 х2 хн

```
xn = dn
Xn-1 = Dn - Cn-1 * xn
...
x1 = d1 - C12X2 - ... - C1nXn
```


```py
def gauss_matrix(A, b):
    n = len(b)
    augmented = np.column_stack((A, b))

    for i in range(n):
        max_row = i + np.argmax(np.abs(augmented[i:, i]))
        if max_row != i:
            augmented[[i, max_row]] = augmented[[max_row, i]]
        
        if abs(augmented[i, i]) < 1e-10:
            raise ValueError("virojdeno")

        augmented[i] = augmented[i] / augmented[i, i]

        for j in range(i+1, n):
            factor = augmented[j, i]
            augmented[j] -= factor * augmented[i]
    
    x = np.zeros(n)

    for i in range(n-1, -1, -1):
        x[i] = augmented[i, -1]
        for j in range(i+1, n):
            x[i] -= augmented[i, j] * x[j]

    return x

A = np.array([[6, -1, -1],
              [-1, 6, -1],
              [-1, -1, 6]], dtype=float)
b = np.array([11.33, 32, 42], dtype=float)

try:
    solve = gauss_matrix(A, b)
    check = A @ solve
    print("A @ x", check)
    print("b:", b)
    print("diff (A @ X - b):", check - b)
except ValueError as e:
    print(e)
```
