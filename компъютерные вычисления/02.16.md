# Сложение и вычитание приближенных чисел

Правила расчёта абсолютной погрешности для разных случаев.

**Абсолютная погрешность алгебраической суммы нескольких приближенных чисел равна сумме абсолютных погрешностей слагаемых.**

## Классический способ

S = a1 + a2 + ... + an (1)

ΔS = Δa1 + Δa2 + ... + Δan (2)

## Второй способ

Применяется при:

* Большом кол-ве слагаемых (n > 10) — оценка абсолютной погрешности суммы по формуле 1 оказывается сильно завышенной для частичной компенсации погрешности разных знаков.
* Если все слагаемые округлены до m-ного десятичного разряда, то статистическая оценка абсолютной погрешности суммы оценивается по правилу Чеботарева:

ΔS = sqrt(3n) * 0.5 * 10^-m, где n > 10

## Третий способ

Если среди слагаемых имеется одно число, абсолютная погрешность которого значительно превосходит абсолютные погрешности остальных слагаемых, то абсолютная погрешность суммы считается равной этой наибольшей погрешности.

При этом в сумме целесообразно сохранять столько десятичных знаков, сколько их в слагаемом с наибольшей абсолютной погрешностью. Предельная абсолютная погрешность суммы не может быть меньше предельной абсолютной погрешности наименее точного (в смысле абсолютной погрешности) слагаемого, поэтому не имеет смысла сохранять излишние знаки и в более точных слагаемых.

**Правило:**

Чтобы сложить числа с различной абсолютной степенью точности, следует:

1. Выделить числа, десятичная запись которых обрывается ранее других, и оставить их без изменения.
2. Остальные числа округлить до наименее точных, сохраняя 1-2 запасных разряда.
3. Произвести сложение полученных чисел, учитывая все сохраненные разряды.
4. Полученный результат округлить на 1 знак.



### Пример

Стороны треугольника:

A = 17,3 см

B = 23,6 см

C = 14,2 см

Δa = Δb = Δc = 0,1 см

Δp = ?

p = 17,3 + 23,6 + 14,2 = 55,1

Классическое правило работает. Δ — сумма трёх слагаемых.

Δp = Δa + Δb + Δc = 0,1 + 0,1 + 0,1 = 0,3

Верных цифр в исходном — 2.

Верных цифр в полученном — 2.

Потерь — 0.

### Пример 2

Надо сложить приближенные числа:

0,348 + 0,183 + 345,4 + 235,2 + 11,75 + 9,27 + 0,0849 + 0,0214 + 0,00034

Каждое слагаемое имеет все верные разряды.

Рассчитать абсолютную погрешность суммы.

S = 0,35 + 345,4 + 235,2 + 11,75 + 9,27 + 0,08 + 0,02 + 0 = 602,07 ≈ 602,1

ΔS = 0,05 + 0,05 = 0,1

(сумма абсолютных погрешностей самых неточных слагаемых — 345,4 и 235,2)

S = 602,1 ± 0,1

S = 602 см ± 0,1





## Относительная погрешность

Относительная погрешность суммы нескольких чисел одного и того же знака заключена между наименьшей и наибольшей из относительных погрешностей слагаемых.

(тот же пример)

δa = 0,1 / 17,33 * 100% = 0,57%

δb = 0,1 / 23,6 * 100% = 0,42%

δc = 0,1 / 11,2 * 100% = 0,89%

δp = 0,3 / 55,1 * 100% = 0,54%

**Относительная погрешность разности двух положительных чисел больше относительных погрешностей этих двух чисел, особенно если эти числа близки между собой, то есть если их разность мала по сравнению с самими этими числами.**

### Пример

Нужно вычислить разность, найти абсолютную и относительную погрешности.

y = x1 - x2

x1 = 0,01234     верных цифр — 4

x2 = 0,01231     верных цифр — 4

y  = 0,00003     верных цифр — 1

Известны абсолютные погрешности этих чисел:

Δx1 = Δx2 = 0,000002

Δy = Δx1 + Δx2 = 0,000004

δy = Δy / |y| = 13,3% ≈ 13%

δx1 = 0,016%

δx2 = 0,016%







# Умножение приближенных чисел

При умножении и делении приближенных чисел складываются **их относительные погрешности**.

Относительная погрешность результата будет записана следующим образом.

## 1 способ

r = (a1 * a2 * a3 * ... * an) / (b1 * b2 * b3 * ... * bm)

δr = δa1 + δa2 + ... + δb1 + δb2 + δb3

## 2 способ

При большом количестве m+n выгоднее пользоваться статистической оценкой, которая учитывает частичную компенсацию погрешностей разных знаков.

С учётом того, что все числа имеют примерно одинаковую погрешность δ, относительная погрешность результата будет рассчитываться по следующей статистической оценке:

δr = (n + m) / sqrt(3(n+m))

## 3 способ

Если у одного из чисел ai, bj относительная погрешность значительно превышает относительные погрешности остальных чисел, то относительная погрешность выражения 1 считается равной этой погрешности.

При этом в результате следует сохранять столько значащих цифр, сколько и в числе с наибольшей относительной погрешностью.

## Практическое правило

1. Чтобы найти произведение нескольких приближенных чисел с различным числом верных значащих цифр, достаточно округлить числа так, **чтобы каждое из них содержало на 1-2 значащие цифры больше, чем число верных цифр в самом неточном множителе**.

2. В результате умножения сохранить столько значащих цифр, сколько верных цифр имеется в наименее точном из сомножителей, или удержать ещё 1 запасную цифру.
