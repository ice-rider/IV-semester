# Вычислительная математика

Исенбаева Елена Насимьяновна

***вычислительная математика*** - раздел математики который изучает круг вопросов связанных с применением вычислительной техники и численных методах при решении практических задач

## Прямые:

* метод кармера
* метод гауса

## Итерационные методы:

* метод простых итераций
* метод Шульца
* метод релаксации

## Нахождение корня квадратного

### Численный алгоритм:

x^2 - a = 0

x^2 = a

x = +\_sqrt(a)

### Итерационный алгоритм:

Xn = 1/2 (Xn-1 + e/(Xn-1))

х0, х1,  …, Хn

Xn ~= sqrt(a)

***численный*** метод решения задач - определенная последовательность операция над числами, т.е. вычислительный алгоритм язык которого числа и арифметические действия

Особенности:

* разработка численного метода предполагает замену (аппроксимацию) исходной задачи 1 некоторым вычислительным алгоритмом 2
* задача 2 содержит некоторый параметр N которого нет в исходной задаче.
* выбором этого параметра N можно добиться любой близости решения задачи 2 к решению задачи 1
* неточная реализация алгоритма вызванная округлениями не меняет 2 свойств

## Приближенные числа. Источники и классификация погрешности.

### Погрешности:

1. ***погрешности самой задачи*** - погрешности связанные с самой постановкой задачи.

*(Неустранимые тип погрешности для математика-вычислителя)*

2. ***погрешности метода*** - часто решить задачу в точной постановке трудно тогда ее заменяют близкой по результатам приближенной задачей.

*(Устранимый тип погрешности => можно изменить метод)*

3. ***остаточный тип погрешности*** - погрешности связанные с наличием бесконечных процессов в математическом анализе. функции, которые используются в формулах, часто задаются в виде бесконечной последовательности или рядов.

**Пример**:

sin(x) = ?                                      - задача 1

sin(X) = x - x^3/(3!) + x/(5!) - x^7/(7!) + …   - задача 2  (… - остаточная погрешность)

4. ***Погрешности округления*** - погрешности связанные с системой исчисления. При изображении даже рациональных чисел в десятичной системе исчисления справа от запятой может быть бесконечное кол-во цифр. например бесконечная переодическая дробь.

**Пример**:

1/3 = 0,(3)

               - абсолютная погрешность

1/3 ~= 0,3;     - 0.5 \* 10^-1

   ~= 0,33;	- 0.5 \* 10^-2

   ~= 0,3333;  - 0.5 \* 10^-4

5. ***Погрешности действий*** - производя вычисления над приближенными числами, погрешности входных данных мы переносим в результат вычислений

*(Неустранимые тип погрешности)*

## Абсолютная и относительная погрешности.

### Абсолютная погрешность.

А - точное число

α - приближенное число

А ~ α.

***приближенное число*** α - число незначительно отличающееся от точного числа А и заменяющее его в вычислениях.

Δα = A - α        - погрешность

A > α => Δα > 0

A < α => Δα < 0

если α не известен, рационально воспользоваться абсолютной погрешностью.

Δ = |Δα| = |A-α|  - ***абсолютная погрешность***

Δq                - ***предельная абсолютная*** погрешность

Δ <= Δq

предельная абсолютная погрешность - всякое число не меньшее абсолютной погрешности этого числа.

в качестве предельной абсолютной погрешности используется как можно меньшее число.

                         α - Δq <= A <= α + Δq

приближение по недостатку ^^^^^^     ^^^^^^ приближение по избытку

### Относительная погрешность.

l1 = 215,5см +\_ 0.5см

l2 = 15,5 см +\_ 0.5см

относительная погрешность - абсолютная погрешность приходящаяся на единицу длины

δ = Δ / |A|

δ = Δ / |α|

δq = Δα / |α|  - ***предельная относительная погрешность***

абсолютная и относительная погрешности определяются с избытком и записываются в виде чисел с одной или двумя значащими цифрами

---------

## Примеры:

Найти абсолютную и относительную погрешности числа Pi 3.14 (3.14159) которая задается двумя и тремя цифрами после запятой

1. x = 3,14

ΔPi = | Pi - x | = | 3.141592 - 3.14 | = 0.001592 ~= 0.0016

δPi = 0.0016/3.14 \* 100% = 0.0509 ~= 0.062

2. $x = 3{,}142$

$\Delta_{Pi} = |3{,}141592 - 3{,}142| \approx 0{,}000407 \approx 0{,}0005$

$\delta_{Pi} = \frac{0{,}0005}{3{,}142} \cdot 100\% \approx 0{,}0159\% \approx 0{,}016\% \approx 0{,}02\%$
